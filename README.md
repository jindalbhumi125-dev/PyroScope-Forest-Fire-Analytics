# PyroScope — Forest Fire Analytics

**Statistical Analysis and Visualization of Forest Fire Patterns Using R**

## About the Project

PyroScope is an R-based data analysis project that explores forest fire observations using statistical methods and data visualization. It examines burned-area patterns, monthly variations, weather conditions, and relationships between numerical variables.

## Objectives

- Analyze forest fire data using R.
- Calculate descriptive statistical measures.
- Explore monthly fire observations and burned-area patterns.
- Identify potential outliers in burned-area measurements.
- Visualize relationships between weather variables and burned area.
- Present data-driven insights and interpretations.

## Technologies Used

- R Programming
- RStudio
- R Markdown
- ggplot2
- dplyr
- tidyr
- knitr
- corrplot

## Dataset

The project uses the Forest Fires dataset from the UCI Machine Learning Repository. It contains observations from forest areas in Portugal, including weather-related variables and recorded burned area.

## Project Features

- Dataset exploration and summary
- Missing-value checks
- Statistical summary of numerical variables
- Monthly fire-record analysis
- Burned-area distribution and outlier analysis
- Weather-related visualizations
- Correlation analysis
- Automatically generated insights and interpretation

## Project Files

| File | Description |
|---|---|
| `PyroScope.Rmd` | R Markdown source code |
| `forestfires.csv` | Dataset used for analysis |
| `PyroScope.html` | Generated analysis report |

## How to Run

1. Install R and RStudio.
2. Download or clone this repository.
3. Open `PyroScope.Rmd` in RStudio.
4. Install any required packages that are not already installed.
5. Update the dataset path in the code if necessary.
6. Click **Knit** to generate the HTML report.

## Key Learning Outcomes

- Applying descriptive statistics to a real-world dataset.
- Creating data visualizations using R.
- Exploring patterns and outliers in environmental data.
- Interpreting correlations carefully.
- Producing an HTML report using R Markdown.

## Limitations

This project explores historical observations. Correlation does not establish causation, and the analysis does not predict future forest fires.
